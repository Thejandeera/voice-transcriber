FreePBX is an open-source telephone system management platform that provides a web-based interface for configuring and controlling Asterisk. Asterisk is the main communication engine that handles calls, extensions, voicemail, call routing, conferencing, and other telephone functions. FreePBX makes these features easier to manage by providing a graphical interface, so administrators do not need to configure every setting manually through command-line files.
With FreePBX, an administrator can create SIP or PJSIP extensions, connect softphones, configure call routes, manage voicemail, view call records, and control security settings. It can be installed on a Linux server and used to build a private telephone system for a home, office, school, hospital, company, or laboratory environment. It is especially useful for organizations that want to manage internal telephone communication without depending completely on traditional telephone systems.
One of the main advantages of FreePBX is its flexibility. It can support different types of users and devices, including desktop softphones, mobile applications, IP phones, and external telephone lines. Extensions can be created for each user, and calls can be made between them over the local network or through the internet. Administrators can also configure features such as call forwarding, call queues, ring groups, voicemail, call recording, and interactive voice response menus.
In this project, FreePBX was installed on a Debian server together with Asterisk. Debian was selected because it is stable, secure, and suitable for server environments. The system was installed inside a virtual machine using VMware Workstation Pro. After the installation, the server hostname, network settings, and required packages were configured.
Two PJSIP extensions were then created in FreePBX. Extension 1001 was configured on MicroSIP, which was installed on a Windows computer. Extension 1002 was configured on Zoiper, which was installed on a mobile phone. Both applications were connected to the FreePBX server using the server IP address, extension number, and extension secret.
Test calls were made between the two devices to confirm that the extensions were registered and that communication worked correctly. Calls were successfully completed from MicroSIP to Zoiper and from Zoiper to MicroSIP. The Asterisk command-line interface was also used to check the status of the PJSIP endpoints and confirm that both extensions were available.
FreePBX was later connected to a Node.js backend through its GraphQL API. The backend used OAuth authentication to request an access token and then sent authenticated GraphQL requests to FreePBX. It retrieved Call Detail Records containing information such as the call date, source number, destination number, call status, total duration, talk time, and recording filename.
The backend also filtered answered calls, missed calls, and calls made during the current day. It calculated useful statistics, including total calls, answer rate, missed-call rate, total call duration, total talk time, and average talk time. Recording playback and download endpoints were also added, allowing available call recordings to be accessed through the backend.
Overall, FreePBX provided a complete platform for managing the telephone system, while Asterisk handled the actual communication. The Node.js backend extended the system by making call information easier to retrieve, process, and display through simple REST-style API endpoints.
